# Verification and Evaluation Plan


The platform will be evaluated through functional testing and comparison with a spreadsheet-based approach to lifecycle record management.

## (1) Testing Plan

| Test | Expected Result | Evaluation Metric |
|---|---|---|
| Product registration | A product is registered with a unique identifier. | Successful registration |
| Lifecycle event recording | Events are saved and displayed in chronological order. | Correctness of event history |
| Search and history retrieval | Users can find items and retrieve their recorded histories. | Completion time and accuracy |
| Access control | Unauthorized users cannot access restricted information. | Permitted and denied access tests |

## (2) Baseline and Measurement Conditions

The proposed baseline is a spreadsheet-based system using separate records for products and lifecycle events.

Both approaches will be evaluated using the same predefined tasks and test dataset, containing a certain number of products and lifecycle events. Search and history-retrieval tasks will be compared by completion time and accuracy under documented, comparable conditions.

## (3) Expected Evaluation Outcome

The evaluation will determine whether the developed platform correctly maintains lifecycle histories, enforces access restrictions, and supports efficient retrieval of product information compared with the baseline.

The testing procedures and dataset will be refined after the project requirements are finalized.
